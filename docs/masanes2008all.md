# All bipartite entangled states display some hidden nonlocality

## Referência

[Masanes, L., Liang, Y. C., & Doherty, A. C. (2008). All bipartite entangled states display some hidden nonlocality. Physical review letters, 100(9), 090403.](https://arxiv.org/abs/quant-ph/0703268)

## Ideia Principal

Caracterizar o conjunto de estados quânticos que pode violar CHSH.

## Principal resultado

Para todo estado quântico emaranhado $\sigma$, existe algum estado $\rho$ que não viola CHSH tal que $\sigma\otimes \rho$ viola CHSH. Logo, $\sigma$ não pode ser substituido por correlações clássicas e como conclusão, emaranhamento é equivalente a não-simulabilidade.

## Relação com o projeto

Primeira evidência (talvez?) de que todo estado emaranhado deve ser, de alguma forma, não-local.
