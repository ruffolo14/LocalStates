# Biblioteca do Projeto

Esta página reune artigos que possivelmente são relevantes para o projeto. 

## Artigos Relevantes ao Projeto

### Sobre emaranhamento e recursos não-locais
- [Werner](werner1989quantum) define pela primeira vez o que significa estados quânticos separáveis e locais. Também mostra que existem estados emaranhados locais. Nota pela primeira vez quais propriedades as funções respostas precisam ter para evitar serem frame functions e se reduzirem a correlações de estados separáveis. 
- [Masanes et.al.](masanes2008all.md) mostram que todo estado emaranhado tem alguma forma de não-localidade oculta e concluem que emaranhamento é equivalente a não-simulabilidade.
- [Buscemi](buscemi2012all.md) mostra que todo estado emaranhado é recurso não-local sob operações LOSR. Em particular, mostra que existem jogos não-locais que testemunham emaranhamento de qualquer estado quântico emaranhado, não importa o quão "fraco" seja.

### Sobre Cenários de Broadcasting
- [Bowles et.al.](bowles2021single.md) definem o que é um cenário de broadcasting. Também propõe o que é um modelo local broadcasting com funções respostas local quanticas.
- [sekatski e Pauwels](sekatski2025all.md) provam que todo estado emaranhado viola o modelo broadcasting local com funções respostas local quânticas.

### Sobre Teorema de Gleason
- [Pitowsky](pitowsky1998infinite.md) propõe que Logical Compactness e o Teorema de Gleason juntos trazem várias consequências para conjuntos finitos de projetores
- [Hrushovski e Pitowsky](hrushovski2004generalizations) Levam a ideia proposta por Pitowsky no artigo anterior adiante, derivando outras consequências. Aqui há uma versão do Teorema de Gleason para um conjunto finito de projetores.
